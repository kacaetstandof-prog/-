# OTCFUNPAY
## Telegram Mini App — «Отзывы»

В проект добавлен Mini App `reviews.html` с:
- просмотром отзывов;
- рейтингом и статистикой;
- добавлением собственного отзыва из Telegram;
- отметкой подтверждённого отзыва для пользователей с завершёнными сделками;
- автоматическим отображением реальных отзывов, сохранённых в сделках;
- отображением отзывов начиная с 10.08.2026.

### Публикация
1. Разверните бота как web-процесс (Procfile уже содержит `web: python bot.py`).
2. Укажите публичный HTTPS-адрес приложения в переменной окружения `WEBAPP_URL` (например, `https://your-domain.example/reviews`).
3. После перезапуска в главном меню появится кнопка «Отзывы» и откроет Mini App.

Если `WEBAPP_URL` не задан, кнопка остаётся в меню, но сообщает администратору, что адрес ещё не настроен.
